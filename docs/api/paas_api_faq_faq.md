# API Reference: faq

Source file: `paas/api/faq/faq.py`

## Whitelisted API Endpoints

### `def create_faq(data)`
Creates a new FAQ.

### `def get_faqs(type=None)`
Retrieves FAQs, optionally filtered by type.

### `def update_faq(name, data)`
Updates an FAQ.

### `def delete_faq(name)`
Deletes an FAQ.
